# 本地数据审核报告

本轮任务：对用户下载的两份公开数据 ZIP 进行真实检查，不执行模型训练。所有图片衍生文件及逐图台账仅保存在已被 Git 忽略的本地 data 目录。

## 数据接入与可读性

Kaggle：21,000 张；Roboflow v1 COCO：9,855 张；合计 30,855 张。全部逐张读取和解码，未发现图片解码错误，已检查的目标框没有越界或非正尺寸；没有 COCO 图片尺寸不一致记录。能解码不代表画质、标签或独立性合格。

Kaggle 每类实际 1,400 张，分布为 train 1,000、validation 200、test 200。目标三类各 1,400 张，共 4,200 张。源数据公布的百分比文字与实际整数数量不完全一致，不直接作为本项目划分标准。

Roboflow 随包声明自动方向校正、拉伸到 640×640、此版本未新增增强；这不能证明上游图片没有已有噪点、遮挡、增强或重复。

## 视觉抽查发现

AI辅助查看了每类24张、共192个图册样本；按哈希 ID 确定性取样，混合来源时分别覆盖来源，并排除相同像素。此处不是人工逐图验收，不以抽查比例估计全量错误率。

- Kaggle 三类样本可见目标食材，但有相似市场背景、手持摆放和相同场景，需要按拍摄关联复核，不能假定每张独立。
- Roboflow 部分图有明显黑白噪点、黑块遮挡、模糊和局部截断。鸡胸肉图册第8、18、21、22、23格可作为复核示例；具体 ID 见 contact_index.csv。
- 玉米图册出现罐装食品、容器与较小模糊区域，不能将所有 corn 标注无条件视为可见原食材；需逐图筛查。
- 鸡翅抽查可见多种裁剪角度及部分目标，仍需检查同父图多框、拍摄关联与部位定义；200个框不能当作200张独立原图。
- 泛鱼图册仅支持“鱼”泛类，不能据此确认鲈鱼；该目录全部保持未确认。
- 泛虾图册混有可见虾、熟制样本、噪点严重与目标不清楚的区域；对虾语义和生熟范围未确认，目录全部保持未确认。
- 已从 ZIP 中取出一个噪点鸡胸肉样本的完整父图复核：`test/DSC_5979_JPG_jpg.rf.f2aa0554128b474d4c1a610d4ac48e0d.jpg`。噪点和黑块存在于来源图片中，不是本轮裁剪生成。对应框为 [425,369,139,51]，裁剪 ID 为 `07d6eae1c0e506eabaffdd51`。

## 重复与划分

全部原图的文件 SHA256 完全重复有4组、4张多余副本；解码RGB像素完全重复也是4组、4张多余副本，两项重叠，不能相加。未发现这4组在同来源原始划分间跨集合。

原图 pHash 距离不超过6的相似候选共16,800对，其中同来源跨原始划分7,334对（Kaggle 7,073对、Roboflow 261对），跨来源131对。分类候选间相似对3,449对。相似对不是已确认重复数量，也不能按对数当作图片数。

AI视觉复核了三组Kaggle跨集样本，均可见同一画面：西兰花 train/0075.jpg 与 validation/1350.jpg，土豆 test/1002.jpg 与 validation/1279.jpg，南瓜 test/1184.jpg 与 train/0422.jpg。拼图见 `data/cache/audit_v1/cross_split_spotcheck.jpg`。证据支持来源划分存在近重复泄漏，不能直接沿用；不能将这个结论扩大为所有16,800对均已确认重复。

已生成 `group_proposals.csv`：把同父图、完全重复及相似候选边按跨来源全局关系保守连接。9,641个分类候选形成4,792个待复核关联组，最大组含260个候选。它们不是已验证独立组：近重复误报可能造成过度合并，同拍摄不同角度也可能漏合并，需审核后再冻结。

未生成正式划分与 manifest；原因是鲈鱼数据缺口、泛虾语义、低质量候选与近重复/拍摄关联仍待解决。先确认这些问题，再拟定80/10/10分组划分，履行三名成员共同冻结类别的要求。
