- AI辅助查看了每类12张、共96张抽查图；未进行全量物种和部位鉴定，不以程序通过声称标签全部正确。

- 鲈鱼有1张来自Roboflow泛fish来源，物种标签不能仅凭来源证明；已单独登记species_review.csv供复核。其余50张来自明确Sea Bass目录，但仍不等于已进行生物学鉴定。
- 少数类总量仅51至114张，鲈鱼验证/测试各5张；类别不平衡明显，单个样本会显著影响小类指标。
- 所有来源都是公开数据；未建立独立烤箱场景external_test，不能用本划分的结果承诺烤箱泛化效果。
- 拍摄个体/场次元数据不完整，相似检索可能误报或漏报，无法证明所有同一拍摄对象均已找全。
- 程序quality_warnings当前仅代表最短边阈值检查结果，不是全面清晰度、语义或背景质量认证。
