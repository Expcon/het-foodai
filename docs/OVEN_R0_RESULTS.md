# R0真实复现与W/S交叉诊断

2026-11-11。分支 `feat/model-oven-r0-observable-replay`，基线 `b7164b5`。这是[既有R0方案](OVEN_A_OBSERVABILITY_REPRO_PLAN.md)的实际执行记录。只运行了一组原A配方的30轮真实探索复现，未训练正式v3、未导出生产ONNX、未更换现场模型或GUI。

**核心结论：精确复现成功。逐轮退化同时涉及参数和BN统计的配合；E30尾批的参数更新有直接负面证据，而尾批统计更新在所测条件下反而改善结果。E28的大幅退化在尾批前已发生。下一组优先只改变学习率，仍不能宣称泛化提升。**

本文所有一致数、Loss和转移均来自相同1,996张已见训练图与原候选目录标签。独立实物验证仍 **BLOCKED**，不是准确率验收、部署选模或冻结test评测。来源、许可、身份及标签限制继承原数据审计，没有新造实物ID、修正标签或加入现场错误图训练。

## 2. Epoch 27→28与29→30：参数和统计具有明显交互

W包括全部可学习参数，**含BN gamma/beta**；S只含39层running mean/variance/counter，其他属性固定。每个组合从独立模型副本、相同无增强输入、model.eval推理；未写入任何checkpoint，混合状态不作为模型发布。两组对角线完全重现已保存固定eval。

### Epoch 27/28

| 组合 | 一致数/1996 | CE Loss |
| --- | ---: | ---: |
| W27/S27 | 1996 | 0.001308 |
| W27/S28 | 1922 | 0.133600 |
| W28/S27 | 885 | 20.341569 |
| W28/S28 | 1750 | 1.795395 |

- 固定W27，只换S：新增74个错误，直接说明统计变化能影响预测。
- 固定S28，只换W：恢复22个、引入194个，净下降172个。
- 固定S27换W则净下降1111个；在W28上将旧统计换为S28恢复961个、引入96个，净恢复865个。

所以有两条不同的算术路径：`1996→1922→1750`（先S再W）和 `1996→885→1750`（先W再S）。参数与统计不是可独立相加的固定贡献，**不能把246个最终错误唯一拆成“多少%是BN、多少%是权重”**。统计更新在新参数下大幅补偿，但二者组合仍失稳。E28错误以corn 136张为主，不是E30土豆错误的简单延续。

## 3. 最后12张是否是主要原因

以下0为该轮尾批forward前，1为step后。所有组合都对完整1,996张固定输入eval，不是只评最后12张。

| 尾批轮次 | W0/S0 | W0/S1（只换统计） | W1/S0（只换参数） | W1/S1 | 实际一步净变化 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 24 | 1996 | 1996 | 1996 | 1996 | 0 |
| 27 | 1996 | 1996 | 1996 | 1996 | 0 |
| 28 | 1722 | 1760 | 1680 | 1750 | +28 |
| 29 | 1961 | 1966 | 1975 | 1975 | +14 |
| 30 | 1936 | 1944 | 1846 | 1857 | -79 |

**E28：不是最后12张引起整轮大幅退化。** 尾批前已错274张；实际一步恢复49个、引入21个，净改善28个。固定W时统计更新净改善38或70个；固定S时参数更新净损42或10个。此前62次更新的具体坏步骤尚未逐步隔离，现有每批Loss/梯度/参数更新日志只能提供定位线索。

**E30：尾批的参数更新是这一次退化的重要直接因素。** 实际一步新增79个错误、没有恢复原错：potato新增70、salmon新增5、sausage新增4。固定旧S时W更新损90个；固定新S时损87个。统计更新在固定旧/新W上分别恢复8/11个，不能将这次尾批损害归为“统计写入破坏”。E29末1975→E30尾批前1936→尾批后1857，净损失分布为此前62步39张、最后一步79张；这是同一轨迹的一致数账目，不是普遍因果比例或泛化贡献。

同样的12张尾批在24、27轮没有改变Top-1，29轮还有改善，因此**没有证明“小Batch这个尺寸本身总会导致失败”**；数据组成、参数状态、优化器历史等尚未单独改变。

此外，从五份真实pre状态分别重放原12张增强tensor，Loss、更新后236个持久张量和357个AdamW状态张量均逐项精确匹配post。没有再次抽增强，没有回写历史或新观测权重。这是实际断点恢复验收，不是额外v3训练。

## 4. 分类头与优化更新：进一步缩小范围

27→28及29→30的119个参数张量全部变化，不只最终线性头；L2描述见[参数差值](experiments/oven_r0_20261111_parameter_deltas.csv)。不同组参数数量/量纲不同，L2大不等于错误贡献大。

按原方案，另做**只交换最终两项linear.weight/bias**、固定其余骨干、头卷积、BN affine及全部S的双向诊断：

| 条件 | 原一致数 | 仅换线性头后 | 恢复/新增错误 |
| --- | ---: | ---: | --- |
| W27/S27骨架装E28线性头 | 1996 | 1996 | 0/0 |
| W28/S28骨架装E27线性头 | 1750 | 1757 | 22/15 |
| W29/S29骨架装E30线性头 | 1975 | 1981 | 7/1 |
| W30/S30骨架装E29线性头 | 1857 | 1853 | 1/5 |
| E30尾批pre骨架装post线性头 | 1936 | 1932 | 0/4 |
| E30尾批post骨架装pre线性头 | 1857 | 1858 | 1/0 |

所测条件下，**最终线性头变化单独不足以重现大幅退化**，尤其不足以解释E30尾批79个新错。尚未分别隔离头部卷积、BN affine、骨干及其交互，不能宣称已定位某一层。所有组合是诊断副本，不是修复候选。

E30尾批在线12/12一致、CE仅0.001110；但head/backbone梯度L2约0.019932/0.060642，对应参数更新L2约0.115166/0.312373。当前Batch Loss很小不代表AdamW更新很小，也不代表更新后eval稳定。AdamW历史动量/二阶矩、自适应缩放及持续特征漂移可能参与，这些量纲不同的范数不能直接相除作因果解释；未进行去动量或改变优化器的受控训练，故仍属上游原因假设。

## 5. 下一轮只改一个变量

**优先做探索性R1：仅将恒定lr从0.001降至0.0003**，保留R0全部数据/顺序、种子、初始化、增强、224预处理、batch/尾批、AdamW其他项、BN策略/动量和epoch数以及观测记录。目的为检验参数更新幅度/特征漂移是否关联上述退化；当前证据没有证明该lr一定更好。

现controlled配方故意锁死lr，不能直接编辑旧recipe绕过。后续先增加且测试“只允许lr与预注册基线不同”的入口，再执行独立新目录R1；本轮未实现或运行R1。不同时改BN momentum、冻结BN、drop_last、scheduler、增强、数据或分辨率。drop_last还会移除图片并改变step数，不作为这次单因素首选。

若R1不能精确对齐除lr外的初始化/输入序列，先排查。对训练图即使更稳定，也只回答机制问题；正式v3选模仍需真实实物/母体来源、会话及人工真值登记、无泄漏独立开发验证与封存test，十二类正式契约由团队确认。保留[现场登记流程](OVEN_INDEPENDENT_VALIDATION_INTAKE_GUIDE.md)，当前不补造身份，不从回看最高点选模型。
